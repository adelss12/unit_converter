# محول الوحدات الشامل | Universal Unit Converter (PWA)

تطبيق ويب تقدمي (Progressive Web App) احترافي، متكامل وسريع للغاية، مصمم خصيصاً للجوال لتقديم أفضل تجربة مستخدم (UI/UX) باللغة العربية مع دعم كامل للعمل بدون اتصال بالإنترنت (Offline First).

---

## 🌟 أبرز المميزات

1. **تصميم عصري ومتجاوب (Mobile First):**
   - يدعم الاتجاه من اليمين لليسار (RTL) مع خط عربي حديث وأنيق.
   - دعم كامل للوضع الداكن (Dark Mode) والوضع الفاتح مع الحفظ التلقائي لاختيار المستخدم.
   - تكيّف مثالي مع جميع شاشات الهواتف الذكية والأجهزة اللوحية والحواسيب.

2. **تحويل لحظي وفوري (Instant Conversion):**
   - يتم تحديث النتيجة فور كتابة أي رقم بدون الحاجة للضغط على زر "احسب".
   - زر سريع ومريح لتفريغ حقل الإدخال بنقرة واحدة (✕).

3. **تبديل الوحدات الذكي (Instant Swap):**
   - زر دائري عائم بلمسة وتأثير بصري حركي يعكس وحدة الإدخال والإخراج وقيمتها فوراً.

4. **نسخ سريع للنتائج:**
   - زر نسخ بجانب النتيجة ينسخ الرقم للحافظة مع إشعار منبثق (Toast) لطيف.

5. **البحث السريع عن الوحدات:**
   - نافذة سفلية منبثقة (Bottom Sheet) للبحث بالاسم العربي، الاسم الإنجليزي، أو الرمز الرياضي.

6. **لوحة مفاتيح رقمية مدمجة داخل التطبيق:**
   - لوحة أزرار لمسية كبيرة مخصصة ومريحة للشاشات اللمسية بالإضافة لدعم لوحة مفاتيح الجوال الأصلية (`inputmode="decimal"`).

7. **سجل التحويلات (History):**
   - حفظ تلقائي لآخر التحويلات في الذاكرة المحلية (`localStorage`).
   - إمكانية استعادة أي عملية سابقة بمجرد الضغط عليها.
   - زر لمسح السجل بالكامل.

8. **نظرة شاملة لجميع الوحدات (All-in-One Quick Grid):**
   - عرض فوري لقيمة الرقم في جميع الوحدات الأخرى لنفس الفئة مع إمكانية التحويل المباشر إليها.

9. **جاهز كتطبيق تقدمي (PWA Ready):**
   - يتضمن `manifest.json` و `Service Worker (sw.js)` مما يتيح تثبيته كأيقونة تطبيق مستقل على شاشة الجوال الرئيسية والعمل 100% بدون إنترنت.

## 🚀 كيفية تشغيل التطبيق ومعاينته على الجوال

### 1. التشغيل المحلي السريع:
- يمكنك فتح ملف `index.html` مباشرة في أي متصفح (Chrome, Safari, Edge, Firefox).
- لتشغيل ميزات PWA والـ Service Worker بشكل كامل، يُفضل تشغيله عبر خادم محلي خفيف:
  ```bash
  # باستخدام بايثون 3
  python3 -m http.server 8080
  
  # أو باستخدام npx serve
  npx serve .
  ```
- بعد ذلك افتح الرابط `http://localhost:8080` في متصفحك.

### 2. المعاينة على شاشة الجوال الحقيقية:
- تأكد أن هاتفك وجهاز الحاسوب متصلان بنفس شبكة الواي فاي (Wi-Fi).
- اعرف عنوان الـ IP المحلي لجهازك (مثلاً: `192.168.1.50`).
- افتح متصفح الجوال (Chrome في أندرويد أو Safari في آيفون) واكتب:
  `http://192.168.1.50:8080`

### 3. تثبيت التطبيق كـ PWA على الجوال:
- **في هواتف أندرويد (Google Chrome):**
  - ستظهر لك لافتة "تثبيت التطبيق" تلقائياً داخل التطبيق، أو اضغط على قائمة المتصفح (⋮) واختر **"تثبيت التطبيق" (Install app)** أو **"الإضافة إلى الشاشة الرئيسية" (Add to Home screen)**.
- **في هواتف آيفون (Apple Safari):**
  - اضغط على زر المشاركة (Share Icon في الأسفل) ثم اختر **"إضافة إلى الصفحة الرئيسية" (Add to Home Screen)**.
- سيظهر التطبيق بأيقونة مخصصة ويعمل بكامل الشاشة وبدون شريط المتصفح وبدون اتصال بالإنترنت!
